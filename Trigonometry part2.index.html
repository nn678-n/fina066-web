สมการตรีโกณมิติ (Trigonometric Equations)

1. สมการตรีโกณมิติ คือสมการที่มีฟังก์ชันตรีโกณมิติเป็นส่วนประกอบ[cite: 2]

2. การแก้สมการตรีโกณมิติ หมายถึงการหามุมที่ทำให้สมการของฟังก์ชันตรีโกณมิติเป็นจริง[cite: 2]

3. หากสมการมีฟังก์ชันตรีโกณมิติหลายชนิด ควรแปลงให้เหลือฟังก์ชันชนิดเดียวก่อน โดยใช้อัตลักษณ์ตรีโกณมิติพื้นฐาน เช่น:[cite: 2]

$\sin^2\theta + \cos^2\theta = 1$[cite: 2]
$1 + \tan^2\theta = \sec^2\theta$[cite: 2]
$1 + \cot^2\theta = \csc^2\theta$[cite: 2]

4. ใช้วิธีแยกตัวประกอบเมื่อเหมาะสม[cite: 2]

5. หามุมคำตอบโดยพิจารณาว่าเป็นฟังก์ชันตรีโกณมิติชนิดใด และใช้เทคนิคที่เกี่ยวข้อง[cite: 2]

ตัวอย่างที่ 1

โจทย์: กำหนดให้ $(\sin\theta + \cos\theta)^2 = \frac{3}{2}$ เมื่อ $0 \le \theta \le \frac{\pi}{4}$ จงหาค่า $\arccos(\tan 3\theta)$[cite: 3]

วิธีทำ:

กระจายกำลังสอง: $(\sin\theta + \cos\theta)^2 = \sin^2\theta + 2\sin\theta\cos\theta + \cos^2\theta = \frac{3}{2}$[cite: 3]

ใช้ $\sin^2\theta + \cos^2\theta = 1$ และ $2\sin\theta\cos\theta = \sin 2\theta$ จะได้ $1 + \sin 2\theta = \frac{3}{2}$[cite: 3]

ดังนั้น $\sin 2\theta = \frac{1}{2}$[cite: 3]

จาก $0 \le \theta \le \frac{\pi}{4}$ คูณทั้งสองข้างด้วย $2$ ได้ $0 \le 2\theta \le \frac{\pi}{2}$ ในช่วงนี้ $\sin 2\theta = \frac{1}{2}$ เมื่อ $2\theta = 30^\circ$ ดังนั้น $\theta = 15^\circ$[cite: 3]

แทนค่าใน $\arccos(\tan 3\theta) = \arccos(\tan 45^\circ) = \arccos(1) = 0^\circ$[cite: 3]

ตอบ: 0[cite: 3]
